# CSS Essentials

## Quick Revision
CSS controls presentation. Learn selectors, box model, flexbox, grid, positioning, responsive media queries and reusable utility classes.

## Key Points
- Understand the definition and when the concept is used.
- Practice one small example after reading the theory.
- Remember time/space complexity or important rules where applicable.
- Use the examples on StudyMate for quick revision.

## Exam Tip
Write the definition first, then explain the core idea, followed by a small example or diagram when appropriate.
