# Web Security Basics

## Quick Revision
Use HTTPS, validate input, avoid exposing secrets in frontend code, protect authentication flows, and understand XSS, CSRF and SQL injection at a conceptual level.

## Key Points
- Understand the definition and when the concept is used.
- Practice one small example after reading the theory.
- Remember time/space complexity or important rules where applicable.
- Use the examples on StudyMate for quick revision.

## Exam Tip
Write the definition first, then explain the core idea, followed by a small example or diagram when appropriate.

## Practice Questions
1. Explain **Web Security Basics** in your own words.
2. Give one real-world use case.
3. List two important points that should be remembered for an exam or interview.
