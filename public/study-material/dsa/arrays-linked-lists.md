# Arrays & Linked Lists

## Quick Revision
Arrays store elements contiguously; linked lists connect nodes using pointers. Key operations: access O(1) for arrays, search O(n), insertion/deletion O(n) in arrays; linked-list insertion can be O(1) when the node position is known.
