# StudyMate

A fully interactive React + Vite + Tailwind study website.

## Features
- Subject-wise study material for DSA, DBMS and Web Development
- Search topics instantly
- Filter by subject
- Quick Notes modal for each topic
- Practice quiz with live score and reset
- Responsive mobile/desktop layout
- Dark/light visual toggle
- Local study-material folders with Markdown revision notes

## Run
1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL shown by Vite.

The study material is stored under `public/study-material/`.
